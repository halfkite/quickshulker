# QuickShulkerMore 1.0.0 — Fabric 基线与移植清单

> 本文保留首次基线的历史计划；当前逐版构建、测试与归档状态以 [Fabric 移植进度](../testing/1.0.0-fabric-port-progress.md) 为准，不以本文早期“待移植”表格判断支持状态。

## 本轮范围

优先 Fabric，基线 Minecraft 26.3 / Java 25。对外名称 QuickShulkerMore，JAR 前缀 `quickshulkermore`，内部 ID 保留 `quickshulker`。只改本基线的品牌、版本、更新选择与测试；不改根目录 1.21.1 或 NeoForge。之前 3.3.0 的功能保留，详见 [3.3.0 容器记录](3.3.0-26.3-containers.md)。

## 版本重置的根因处理

单独把版本号改为 1.0.0 会让旧更新检查把历史 3.x 标签认作更新，因此需隔离发布标签：`quickshulkermore-fabric-<模组版本>-<Minecraft版本>`。仅相同加载器、相同 Minecraft 的 More 稳定标签参与比较，忽略旧标签、其他加载器、其他游戏版本、非数字版本以及超长数字。

模组元数据明确限制 Minecraft 26.3，避免误把这个 JAR 安装到旧游戏版本。配置、资源、网络通道、Mixin 类名保持不变；Mod Menu 链接指向本 fork，原作者与上游出处仍保留。

## 混装测试边界

| 客户端 | 服务端 | 基础验收目标 |
| --- | --- | --- |
| 上游 QuickShulker | More | 保留旧功能，不向旧客户端发送未知新菜单/数据包 |
| More | 上游 QuickShulker | 普通潜影盒使用旧协议；新功能在服务器不支持时安全降级 |
| More | More | 全功能对照组 |

本轮自动化使用独立编译的上游原始 OpenShulkerPacket（仅更改包名，固定提交与 MIT 出处见 `src/upstreamWire/README.md`），直接调用两个编码器，不使用反射或自定义类加载器，也不拿 More 的同一编码器自编码自解码。两方向分别测试普通槽位、负数及整数边界，确认通道、四字节长度、读完全部负载。边界测试只证明编码一致，不代表服务端应允许这些非法槽位；来源校验测试仍单独保留。

早期品牌构建曾通过 130 项检查，但它早于后续注册表兼容、无反射和文件时间戳调整，不能作为最终验收结果。最新构建已通过 133 项检查，实际产物见文末。**未完成真实客户端登录的两向混装联机**，也未完成 GUI 视觉或 AMS 联合运行，不能把交叉编解码写成“混装联机通过”。

### Fabric 菜单注册表兼容修复

Fabric 26.3 将 MENU 标记为同步注册表。额外注册陶罐、展示架和合成器菜单，即使开菜单前检查能力，也可能在更早的注册表握手阶段被旧客户端拒绝。因此 Fabric 不增加这三个注册 ID，保留上游 `quickshulker:bundle_item` 作为既有传输入口；仅向声明支持 `portable_menu_v1` 的客户端，在 vanilla OpenScreen 之前顺序发送专用界面种类。客户端一次性消费该消息后创建真实 1 格/3 格/原生合成器菜单，之后的 vanilla 槽位同步不变。普通收纳袋没有该消息时仍使用原菜单。断线清除待处理界面状态。

此消息是能力协商后的界面选择，不是把陶罐伪装成五格漏斗；不修改原版客户端，也不注入 AMS 方法。注册表集合与真实槽数新增自动断言。混装基线先以两端上游默认收纳袋配置为准；上游本身禁用 bundle 注册等特殊配置仍需额外握手验证。

### 无反射 AMS 规则读取

Fabric 的 AMSCompat 改为可选、延迟链接的公开静态字段读取；无反射查类/查字段/调用方法。`amsApi` 源集仅含已核对的两个编译期字段签名，不能出现在运行时或 JAR 中。来源见 `src/amsApi/README.md`。不安装 AMS 时不解析可选类；API 改名或字段缺失时明确警告，并保留已有容量，不把未知 API 说成规则已关闭。支持范围仅限已核对的公开字段 API，私有或 lazy API 不未经核对猜测适配。旧配置序列化库内部实现未在本轮重写；本轮业务兼容和测试不使用反射。

### 测试版时间戳与 GitHub 构建

本地默认文件名为 `quickshulkermore-1.0.0-26.3-test-YYYYMMDD-HHMMSS.jar`（香港时区）；版本元数据仍是 `1.0.0-26.3`。可用 `-PbuildTimestamp=YYYYMMDD-HHMMSS` 固定一次测试构建的文件名。GitHub Actions 的 `GITHUB_ACTIONS=true` 自动禁用时间戳，也可显式 `-PofficialBuild=true` 输出 `quickshulkermore-1.0.0-26.3.jar`。

新增 `.github/workflows/build-fabric.yml`，仅构建 26.3 Fabric，上传无时间戳 JAR 与 SHA-256。工作流尚未推送/在 GitHub 执行，不把本地配置检查写成 Actions 已运行成功。`printArtifactName` 任务输出实际文件路径；归档脚本仍为每次成功 build 创建新时间戳目录，不覆盖旧包。

真实联机必须另用独立测试实例与备份存档，固定同一游戏版本/加载器并记录上游 JAR、More JAR 的哈希。依次检查登录握手、手持/背包右键与快捷键、Shift、关闭重开、断线重连，以及不支持功能的安全拒绝。AMS 大潜影盒 54 格和长按拖拽需重点验证；原版客户端自身的 27 格写回逻辑不能仅凭 More 服务端推断安全。

## Fabric 移植范围（源码盘点，不是已支持声明）

用户目标为 Minecraft **1.21 至 26.3**，不是只做 1.21.1。当前只构建并交付 26.3；基线验收后逐版本移植，不能只改依赖版本或重命名 JAR。

| 目标版本 | 已有参考与状态 |

| 26.3 | 当前 1.0.0 Fabric 基线，已开始构建与自动测试 |

| 1.21.6 / 1.21.7 | 有上游标签，但抽查 `3.0.1-1.21.6`、`3.0.1-1.21.7` 的 gradle.properties 均实际指向 1.21.8；不能直接认定运行兼容 |

每版均需完整 build、独立协议/来源回归、时间戳归档与 SHA-256；真实客户端/AMS 验收另列。按 build-game-mods 技能，基线先交付并等待明确确认，未确认前不修改其他游戏版本源码。
