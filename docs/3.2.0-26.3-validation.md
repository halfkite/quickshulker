# QuickShulker 3.2.0 / Minecraft 26.3

26.3 为主要开发版本；1.21.1 为兼容维护版本。两种加载器与旧版本代码保存在同一仓库目录布局中，不依赖切换 Git 分支。

## 上游依据

- Fabric：MoRanpcy/quickshulker `26.3`，提交 `3fb956eb9ee1abf3e8df4cbe9174289c64aa6a02`。
- NeoForge：同上游 `26.3-neo`，提交 `ba855a8344bf76c317c0e3fa28cb1c5a1a369452`。
- 保留上游 26.3 的 SDL 鼠标事件修复、收纳袋菜单、音效、快捷键与新界面 API。
- 未参考 Carpet-FGA-Addition 的功能代码。

## 同步功能

- 可选 AMS 规则反射：`largeShulkerBox` / `largeEnderChest`，不注入 AMS 节点；已有高位槽始终保留，末影箱使用玩家实际容量。
- 大潜影盒显示原版 9×6 菜单，不依赖 AMS 对潜影盒菜单的修改；批量存取共享容量保留实现。
- 砂轮、锻造台、制图台快捷打开，成组工作站不消耗，远程菜单覆盖距离/方块检查。
- 从真实外部容器槽打开单个潜影盒；独立协议携带菜单 ID 和槽 ID，服务端检查光标、菜单、类型和来源。
- 普通潜影盒仍使用旧协议四字节，新功能通道检测后才发送；NeoForge 新通道使用可选注册。
- 数量为 1 的箱子、陷阱箱、木桶、漏斗、投掷器、发射器、陶罐、合成器、熔炉、烟熏炉、高炉、酿造台物品存储编辑；不执行物品内加工/红石。
- 默认 `quickContainers=true`、`quickContainersCreativeOnly=true`；OP 可即时修改、同步并持久化，指令与 1.21.1 相同。
- 源槽保护覆盖普通点击、Shift 合并、交换和创造批量协议；对象引用或外层来源失效时拒绝写回。
- 读取 26.3 的 TypedEntityData 方块实体组件，保留合成器禁用槽和其他元数据；拒绝未展开战利品表。
- 配置界面新开关及英/简中/繁中/韩文文本；更新检查改查本 fork，按加载器选择版本标签。

上游 26.3 未提供可构建的 Reinforced Shulker 第三方适配，因此不把旧版二进制或类注入到新版本。保留其 UpgradableShulker 扩展路径；第三方模组的 26.3 专用集成需对应依赖和联合验证。

## 验证

- Java 25；Fabric Gradle 9.5.1 / Loom 1.17.21；NeoForge Gradle 9.2.1 / ModDev 2.0.147。
- Fabric 回归通过 Knot 启动；NeoForge 使用官方 ModDev JUnit 和 EphemeralTestServerProvider 临时服务器。
- Fabric 测试通过原版 VanillaRegistries 和 DATA_COMPONENT_INITIALIZERS 绑定默认组件；NeoForge 使用临时服务器实际加载的注册表/组件，不用空组件替代 26.3 生命周期。
- 覆盖旧协议长度、通道隔离、持久化、高位槽保存、元数据保留、禁用/填充槽及替换来源后的会话拒绝。
- 不把构建或组件测试描述为游戏内联机验收。

## 游戏内验收

备份存档后分别测试两个加载器：AMS 规则开关及第 54 格读写/长按批量转移；普通容器手持/背包打开、关闭重开和放置保存；OP 指令及重启持久化；生存权限开关；源物品被玩家、漏斗或其他模组替换；结果槽、创造目录、光标持物及过期菜单拒绝。三个工作站需验证输入、输出、Shift 和关闭返还。没有 AMS 的实例也必须检查普通 27 格行为。
