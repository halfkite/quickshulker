# QuickShulkerMore

[English](README_en.md) · [GitHub Releases](https://github.com/halfkite/quickshulkermore/releases)

QuickShulkerMore 是 [QuickShulker](https://github.com/MoRanpcy/quickshulker) 的非官方扩展版，增加 Carpet AMS Addition 大容器兼容、快捷工作站和快捷容器。项目遵循上游 MIT 许可证。

当前模组版本为 **1.0.0**，主要开发版本是 Minecraft `26.3` / Fabric，支持版本为 Minecraft `1.21-26.3` Fabric 加载器

## 原有功能 
- 按 K 或右键打开手持或背包中的物品界面。内置支持工作台、切石机、潜影盒、末影箱、铁砧和收纳袋;
- 拖着容器右键物品可存入；右键背包空槽可取出；按住右键可批量存入或取出。
## 新增功能
- 兼容 [Carpet AMS Addition](https://github.com/Minecraft-AMS/Carpet-AMS-Addition) 的 54 格`大潜影盒argeShulkerBox`和`大末影箱largeEnderChest`;
- 快捷打开工作方块增加对 `砂轮、锻造台、制图台和织布机` 的支持;
- 增加快捷容器功能 `箱子、木桶、漏斗、投掷器、发射器、陶罐、合成器、炉类、酿造台、各种铜箱子和各种材质展示架` 可以在背包内右键打开，使用对应容器的实际槽位，合成器支持配方合成和锁定空槽，`熔炉、酿造台`可以放入物品，但是放置后才会运行，此功能默认创造可用，生存使用需要改为 `true` ；
- 可从容器内右键打开其中的潜影盒。源物品槽会在服务端验证并受到保护。

## 安装使用

- 将 JAR 放入对应实例的 `mods` 文件夹;
- 客户端服务端安装 `QuickShulkerMore` 与原模组 `QuickShulker` 都可以 正常使用原功能，要使用完整快捷容器功能，请让客户端和服务端安装同版本 `QuickShulkerMore`;
- 不要同时安装原版 `QuickShulker` 与 `QuickShulkerMore` 因为两者使用相同的内部模组 ID。
